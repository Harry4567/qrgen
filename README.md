QRGen est un simple générateur de QR code. Il vous suffit de mettre ces 3 fichiers sur votre site (pensez à rajouter un supprimer le commentaire et à mettre le chemin d'accès de votre favicon ligne 9 de l'index.html si vous souhaitez avoirun favicon), et vous pourrez générer des qrcode, ainsi que toutes les personnes le souhaitant. Il est possible de mettre le logo souhaité au centre du qr code
